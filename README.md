# Богатыри: прототип боя

Beat'em up по мотивам былин. Unity 6, ПК, пиксель-арт.
Это первый прототип: бой на серых фигурах, без настоящего арта. Цель одна: понять, весело ли драться.

## Как запустить

1. Установи **Unity 6 LTS** (6000.0.x) через Unity Hub. Подойдёт любая версия 6000.0.
2. В Unity Hub: **Add → Add project from disk** и выбери эту папку.
3. При первом открытии Unity скачает пакеты. Если спросит про новую систему ввода (*Input System… enable the new backends?*), нажми **Yes**: редактор перезапустится.
4. Открой любую пустую сцену (та, что открылась по умолчанию, подходит) и нажми **Play**. Уровень собирается сам из кода.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Ходить (вбок и в глубину) | WASD или стрелки | левый стик, крестовина |
| Лёгкий удар, серия из трёх | J | X / □ |
| Тяжёлый удар; по лежачему врагу — добивание | K | Y / △ |
| Схватить врага, подобрать оглоблю или бочку, бросить | L | B / ○ |
| Заново | R | Start |

В захвате: J бьёт коленом (на третьем ударе враг улетает), K или L бросает врага во всех остальных.

## Что есть

- **Сидор** (серый): серия из трёх тычков, третий сбивает с ног; тяжёлый удар; добивание лежачего; захват, удары коленом и бросок.
- **Разбойники** двух видов: *дубинщик* (медленный, бьёт сильно и сбивает с ног) и *кистенёк* (быстрый и слабый). Нападают не больше двух сразу, остальные ходят вокруг.
- **Оглобля** — длинный удар, ломается после 8 попаданий. **Бочка** — бросок, сбивает с ног всех на пути.
- Брошенный разбойник тоже сбивает своих.
- Четыре волны врагов. Камера едет только вперёд и стоит, пока волна не разбита, потом мигает «ВПЕРЁД».
- Остановка кадра при ударе и тряска камеры — чтобы удар ощущался.

## Что проверяем

Драться весело даже квадратами? Если нет — правим бой (скорости, окна серии, отдачу), а не рисуем.
Все числа ударов собраны в начале `Player.cs` и `Enemy.Create` в `Enemy.cs`, их удобно крутить.

## Устройство кода

Всё в `Assets/Scripts/Prototype`. Одна единица мира = один пиксель игры, экран 384×216.

- `Stage.cs` — уровень, волны, камера, временный HUD; сам запускается при Play.
- `Fighter.cs` — общее для героя и врагов: здоровье, реакция на удары, падение, захват.
- `Player.cs`, `Enemy.cs` — управление героем и поведение разбойников.
- `Combat.cs` — попадания и описание ударов. `Items.cs` — оглобля и бочка.
- `Feel.cs` — остановка кадра и тряска. `GameInput.cs` — клавиатура и геймпад. `Art.cs` — серые прямоугольники вместо спрайтов.
